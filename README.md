# 🔤 Text Case CLI

A lightweight Python command-line tool for converting text into different naming and formatting styles.

## Features

- UPPERCASE
- lowercase
- Title Case
- snake_case
- kebab-case
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
Enter text: My Awesome Python Project

✨ Results
===================================

UPPERCASE   : MY AWESOME PYTHON PROJECT
lowercase   : my awesome python project
Title Case  : My Awesome Python Project
snake_case  : my_awesome_python_project
kebab-case  : my-awesome-python-project
```

## Built With

- Python
- Regular Expressions
